# Vaughn McManamna's Portfolio

A single-page portfolio featuring software, machine learning, distributed systems, data visualization, and computer graphics projects.

## Structure

- `index.html` — portfolio page, styling, and interactions
- `assets/images/` — profile and project preview images
- `assets/video/` — optimized project demo videos
- `documents/` — downloadable résumé
- `projects/` — source files linked from project entries

The site is static and can be opened locally through `index.html` or deployed directly with GitHub Pages.
